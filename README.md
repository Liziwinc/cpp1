Проект представляет собой учебную реализацию структуры данных **Очередь (Queue)** на языке C++. Основной акцент сделан на использовании шаблонов проектирования и полиморфизма.

### Технические особенности:
- **Шаблонные классы:** Очередь реализована как `template <class DataType>`, что позволяет работать с любыми типами данных (int, double, char и т.д.).
- **Абстракция:** Создан базовый абстрактный класс `Queue`, определяющий интерфейс (`EnQueue`, `DeQueue`, `Front`).
- **Кольцевой буфер:** Реализация `QueueVector` использует логику кольцевого массива для эффективного управления памятью.
- **Обработка данных:** Включена функция поиска минимального отрицательного элемента в очереди без её окончательного разрушения.

### Функционал:
- Добавление/удаление элементов.
- Проверка на полноту и пустоту контейнера.
- Вывод текущего состояния очереди в консоль.
